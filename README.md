# Number Guessing Game

Bu proje, Node.js ve Express.js kullanılarak geliştirilmiş, etkileşimli bir sayı tahmin oyunudur. Kullanıcının sunucu tarafından üretilen gizli sayıyı bulmaya çalıştığı minimalist bir deneyim sunar.

## 🛠️ Teknolojiler

* **Backend:** [Node.js](https://nodejs.org/) & [Express.js](https://expressjs.com/)
* **View Engine:** [EJS](https://ejs.co/)
* **Frontend:** Vanilla JS & CSS3 (Flexbox/Grid/Animations)
